# 04 — Flowcharts

One Mermaid flowchart per algorithm. GitHub and VS Code (Markdown Preview Mermaid) render them directly.

Rules:
1. File name = `FC-nnn-<same slug as ALG-nnn>.md`.
2. Every node label starts with the algorithm step number it implements.
3. Every flowchart has at least one terminal node and shows every failure exit.
4. If the algorithm changes, the flowchart changes in the same commit (`npm run plans:check` checks that the file exists and contains a mermaid block).
